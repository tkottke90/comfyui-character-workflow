Character Workflow Utility

How a character moves through the system

A process map, not a gate — every stage below can be revisited after the fact. Each card is a real screen (see the Screens page). This is the same sequence as the design document's progress model, §8.

Character List

Open an existing character, or start a blank one.

① Draft

Spec Builder

Structured attributes compile into the frozen identity block live.

② Casting

Casting

Pre-flight, then a seed-sweep batch — live gallery, one exact seed each.

Winner Audit & Lock

Forced side-by-side check vs. spec before a seed can freeze.

③ Refinement

Refinement Chain

One screen, three internal steps on the same image — face detail → cleanup → upscale.

④ Anchor kit

Face Crop

Adjustable suggestion. Becomes the only face reference downstream.

View Generation

One card per view — reorientation is always an explicit choice.

Polish & Fixes

Fixes stay locked until polish is accepted on that asset.

⑤ Kit-complete

Downstream Validation

Three throwaway checks: new pose, new outfit, no template.

Dataset & Training

Tracked here; the campaign and training run outside this tool for now.

⑥ Done

lora-trained

Adapter stack retired for this character.

Template Library

Not part of this line at all — uploaded once, reused from Casting and View Generation by every character after it.

Three guarantees hold on every card above, not just one of them:
→ nothing is final until it's accepted into the character file
→ every screen shows what can be done next — never assumed, never remembered
→ any card can be revisited later; this is a progress indicator, not a gate
