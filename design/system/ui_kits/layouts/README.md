# Layouts UI kit

The three canonical TDK_Design page layouts, built from the design-system components.

- `sidebar-layout.html` — the preferred two-column layout: green `SidebarNav` aside (240px) + main content column (max 960px). Interactive: nav, tabs, dark-mode toggle, delete dialog, toasts. Collapses to a stacked top bar under 720px.
- `single-action.html` — centered card (max 400px) for login / focused tasks; logo above, one primary full-width action.
- `stacked-layout.html` — green top header over a single centered column; shown with the numbered Stepper onboarding flow.
- `index.html` — switcher that previews all three.
